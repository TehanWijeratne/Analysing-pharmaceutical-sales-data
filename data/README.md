# Data folder



This folder is empty in the repository on purpose..



## How to get the data

1. Go to https://www.kaggle.com/datasets/milanzdravkovic/pharma-sales-data

2. Download the dataset.

3. Extract `salesdaily.csv` and place it in this folder, so the path is `data/salesdaily.csv`.
